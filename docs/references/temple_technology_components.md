### C. The Āgamic Engineering Manuals

**What Are Āgamas?**

**Āgama** (आगम) = "That which has come down" (from Sanskrit root √ā-gam, "to approach")

**Three Main Traditions:**

1. **Śaivāgamas** (28 primary texts) — For Śiva temples
2. **Vaiṣṇavāgamas** (Pāñcarātra/Vaikhānasa) — For Viṣṇu temples  
3. **Śāktāgamas** (64 Tantras) — For Devī temples

**Structure of Āgamic Texts:**

Each Āgama typically contains four sections (pādas):

| Pāda | Sanskrit | Content | Engineering Parallel |
|------|----------|---------|---------------------|
| 1 | **Jñāna Pāda** | Philosophy, metaphysics | Theoretical physics |
| 2 | **Yoga Pāda** | Meditation, practices | Applied psychology |
| 3 | **Kriyā Pāda** | Rituals, worship | Operating procedures |
| 4 | **Caryā Pāda** | Temple construction, iconography | **Engineering specifications** |

**This treatise focuses on Caryā Pāda** — the engineering manuals.

### D. Key Difference: Āgamas vs. Śilpa Śāstras

**Often Confused:**

- **Āgamas** = Religious texts (include temple architecture as part of worship system)
- **Śilpa Śāstras** = Technical manuals (dedicated entirely to architecture, sculpture, proportions)

**Relationship:**

```
ĀGAMAS establish:
- WHICH deity gets WHICH type of temple
- RITUAL requirements (how many doors, where to place fire altar, etc.)
- THEOLOGICAL significance of each component

ŚILPA ŚĀSTRAS provide:
- PRECISE measurements (down to aṅgula/finger-width)
- MATERIAL specifications (which stone, which wood)
- CONSTRUCTION techniques (how to carve, how to erect)
```

**Both are needed.** Āgamas give the "why," Śilpa Śāstras give the "how."

**Example from Kāmikāgama (Chapter 43-45):**

> "The vimāna above a Śiva liṅga shall have an **odd number** of storeys (3, 5, 7, 9, 11, 13...). The vimāna above Viṣṇu shall have an **even number** (2, 4, 6, 8, 10, 12...)."

**Why?**
- Śiva = Transcendent consciousness (odd = incomplete, pointing beyond)
- Viṣṇu = Manifest sustainer (even = complete, balanced)

**Śilpa Śāstra then specifies:** "For a 5-storey vimāna, each successive tier reduces by 1/7th in width..."

- **Śiva** = Formless (nirguna) → Odd = Incomplete, pointing to infinity

- Built 1010 CE by Rājarāja Chola I

#### 2. Proportional Diminution

**Kāśyapa Śilpa Śāstra (XLV.31-33):**

> "Each successive tier shall reduce in width by 1/7th of the base tier. The height of each tier shall be 1/9th of the base width."

**Mathematical Formula:**

```
Base width = W₀
Tier n width = W₀ × (6/7)ⁿ
Tier n height = W₀ / 9

Total vimāna height = (W₀/9) × number of tiers
```

**Example Calculation:**

- Base width (W₀) = 14 meters
- 5-tier vimāna
- Tier 1: 14 m wide, 1.56 m tall
- Tier 2: 12 m wide, 1.56 m tall
- Tier 3: 10.3 m wide, 1.56 m tall
- Tier 4: 8.8 m wide, 1.56 m tall
- Tier 5: 7.5 m wide, 1.56 m tall
- **Total height:** 7.8 meters

**Result:** Pyramidal/stepped structure.

**Acoustic Purpose:**

Each tier acts as a **resonant cavity** at progressively higher frequencies.

Lower tier = Lower frequency (bass)
Upper tier = Higher frequency (treble)

**Full-spectrum resonance chamber.**
